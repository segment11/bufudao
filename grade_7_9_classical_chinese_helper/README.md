# 文言文助学 — 7-9年级人教版

帮助七至九年级学生背诵和理解文言文的互动学习工具。

## 功能

- **注释阅读**：点击原文中的关键词，查看拼音、释义和词法分类（实词、虚词、通假字、词类活用、古今异义、特殊句式）
- **译文对照**：一键显示/隐藏现代汉语翻译
- **历史背景**：作者简介、写作背景、时代关键词
- **地理溯源**：古地名与现代地名的对应关系
- **逐层遮挡背诵**：四档渐进式遮挡，从全文到全隐藏，按段落逐步推进，进度自动保存
- **关键词填空测验**：从注释词中自动生成选择题，即时反馈对错，统计正确率
- **易错字提醒**：标注常写错的字词
