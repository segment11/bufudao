# 数学助学 — 7-9年级人教版

帮助七至九年级学生掌握代数、几何、函数等核心数学概念的互动学习工具。

## 功能

- **知识点精讲**：每个章节划分为多个小节，涵盖定义、公式、性质与例题
- **可视化演示**：几何图形、函数图像、坐标系等配以 SVG/Canvas 交互图示
- **分层练习**：选择题、填空题、计算题、证明题四种题型，难度分为基础、中等、提高
- **进度追踪**：自动保存学习进度，标记已掌握与待巩固的知识点
- **章节导航**：按年级、学期、单元跳转，快速定位学习内容
- **深色模式**：支持浅色/深色主题切换

## 已收录章节（29章）

| 年级 | 章节 |
|------|------|
| 七上 | 有理数、整式的加减、一元一次方程、几何图形初步 |
| 七下 | 相交线与平行线、实数、平面直角坐标系、二元一次方程组、不等式与不等式组、数据的收集、整理与描述 |
| 八上 | 全等三角形、轴对称、三角形、整式的乘法与因式分解、分式 |
| 八下 | 二次根式、勾股定理、平行四边形、一次函数、数据的分析 |
| 九上 | 一元二次方程、二次函数、旋转、圆、概率初步 |
| 九下 | 反比例函数、相似、锐角三角函数 |
