# 初中英语助学 — 7-9年级人教版

帮助七至九年级学生学习和复习英语的互动学习工具。

## 功能

- **词汇学习**：查看单词的音标、词性、释义和例句
- **语法讲解**：重点语法解析，例句说明，相似语法对比
- **场景对话**：情境对话练习，配文中英对照
- **阅读理解**：阅读短文，关键词注释，配套理解题
- **写作练习**：作文范文展示，关键词短语提示，层级评分
