# 英语助学 — 7-9年级人教版

帮助七至九年级学生学习英语的互动学习工具，覆盖词汇、语法、对话、阅读、练习、写作六大模块。

## 功能

- **词汇学习**：单词卡片含IPA音标、词性、例句，搜索和词性筛选，配套教学图片
- **语法讲解**：每个单元1-2个语法点，详细解释配中文对比，例句和图示
- **情景对话**：角色扮演模式，支持显示/隐藏翻译，对话配场景插图
- **阅读理解**：点击单词查看注释，全文翻译，配套理解题（可折叠答案）
- **互动练习**：填空题、匹配题、排序题、改错题，即时反馈
- **写作范文**：A/B/C三级范文，关键词短语高亮，支持按主题和难度筛选
- **中考考点**：七、八、九年级高频语法点，对比易错点
- **不规则动词表**：100+常用不规则动词，可搜索
- **发音指南**：常见发音难点（th、v/w、l/r等），配对比练习
- **深色模式**：支持浅色/深色主题切换
